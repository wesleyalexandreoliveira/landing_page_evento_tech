# Semana Acadêmica de Tecnologia da Informação

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma landing page para um evento fictício denominado **Semana Acadêmica de Tecnologia da Informação**.

A página foi criada como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de aplicar na prática os conhecimentos adquiridos em sala de aula sobre desenvolvimento web.

## Objetivo

Apresentar uma proposta de evento acadêmico de tecnologia, reunindo informações sobre sua programação, palestrantes, temas abordados e inscrições.

## Tecnologias utilizadas

- HTML5 – Estruturação do conteúdo da página.
- CSS3 – Estilização e organização visual dos elementos.

## Estrutura do projeto

- `index.html` – Estrutura principal da página.
- `style.css` – Estilização da landing page.
- `components/fonts/` – Arquivos de fontes utilizadas.
- `components/images/` – Imagens utilizadas no projeto.
