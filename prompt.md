# Prompts utilizados no desenvolvimento da Landing Page

**1. Background com efeito quadriculado**

Como criar um background utilizando CSS com uma cor azul-marinho, efeitos de luz e um padrão quadriculado ao fundo?

**2. Links da navbar**

Como criar links na navbar para direcionar o usuário às diferentes seções da página? Como controlar o espaçamento entre os itens do menu?

**3. Linha de separação**

Como adicionar uma linha horizontal discreta para separar a navbar do conteúdo da página utilizando CSS?

**4. Section 1 – Texto sobre a imagem**

Como posicionar uma frase sobre uma imagem de fundo utilizando HTML e CSS, mantendo o texto centralizado e legível?

**5. Section 2 – Criação e alinhamento dos cards**

Como criar cards utilizando HTML e CSS e organizá-los lado a lado, mantendo o mesmo espaçamento e alinhamento entre eles?

**6. Section 4 – Efeito nos cards da programação**

Como utilizar CSS para fazer os cards se movimentarem levemente para cima quando o usuário passar o mouse sobre eles, com uma transição suave?

**7. Section 5 – Cards dos palestrantes**

Como criar cards que contenham a imagem dos palestrantes, seus nomes e cargos ou empresas, mantendo todos os elementos organizados dentro de cada card?

**8. Section 6 – Seleção de curso no formulário**

Como criar um campo de seleção em um formulário HTML que permita ao usuário escolher entre dois cursos, Análise e Desenvolvimento de Sistemas (ADS) e Sistemas de Informação (SI)?

9. **Estrutura principal do HTML**

Como organizar a estrutura HTML de uma Landing Page para um evento acadêmico, utilizando as tags semânticas e dividindo o conteúdo em diferentes seções?

10. **Organização das seções da página**

Como estruturar as seis seções da Landing Page utilizando a tag `<section>` e identificadores (`id`), permitindo organizar o conteúdo e facilitar a navegação?

11. **Estilização geral com CSS**

Como organizar o CSS para padronizar as cores, fontes, tamanhos, espaçamentos e alinhamentos de uma Landing Page, mantendo uma identidade visual consistente?

12. **Layout com CSS Grid e Flexbox**

Como utilizar CSS Grid e Flexbox para organizar os elementos da página, distribuindo textos, imagens e cards de maneira alinhada e proporcional?

13. **Estilização dos elementos das seções**

Como aplicar estilos específicos aos títulos, subtítulos, parágrafos, imagens e cards de cada seção, mantendo a identidade visual da página?

14. **Responsividade para diferentes dispositivos**

Como utilizar Media Queries no CSS para adaptar o layout da Landing Page para computadores, tablets e smartphones, ajustando colunas, imagens, fontes e espaçamentos?

15. **Ajustes de responsividade no cabeçalho**

Como ajustar o cabeçalho da Landing Page para telas de tablets e smartphones, organizando o título, os links de navegação e o botão de inscrição sem sobreposição ou falta de espaçamento?

17. **Configuração inicial do CSS**

Como organizar o arquivo CSS e vinculá-lo ao HTML para aplicar estilos à Landing Page, mantendo o código organizado e de fácil manutenção?

18. **Criação do background**

Como criar um background escuro em tons de azul-marinho, utilizando gradientes radiais e efeitos de quadriculado para dar profundidade ao visual da página?

19. **Configuração de fontes personalizadas**

Como utilizar `@font-face` para importar fontes externas e aplicá-las em diferentes elementos da Landing Page?

20. **Padronização de cores e tipografia**

Como definir uma identidade visual consistente utilizando cores, tamanhos de fontes, pesos e espaçamentos para títulos, subtítulos e parágrafos?

21. **Organização dos elementos com CSS Grid**

Como utilizar CSS Grid para organizar textos, imagens e cards em colunas, mantendo o alinhamento e o espaçamento entre os elementos?

22. **Alinhamento com Flexbox**

Como utilizar Flexbox para alinhar e distribuir os elementos do cabeçalho, menus de navegação, botões e conteúdos internos dos cards?

23. **Estilização dos cards**

Como criar cards com cores de fundo, bordas, espaçamentos, cantos arredondados e efeitos visuais, mantendo o padrão de design entre as seções?

24. **Estilização de imagens**

Como controlar dimensões, proporções, posicionamento e bordas das imagens para manter uma apresentação visual adequada na Landing Page?

25. **Efeitos de interação**

Como utilizar os seletores `:hover` e as propriedades de transição do CSS para criar efeitos visuais nos botões, links e cards quando o usuário interagir com eles?

26. **Estilização do formulário**

Como organizar e estilizar os campos de entrada, seletores e botão de envio de um formulário de inscrição, mantendo a consistência visual com o restante da página?

27. **Adaptação da Landing Page para dispositivos móveis**

Como tornar a Landing Page responsiva, adaptando sua estrutura e seus elementos para funcionar corretamente em tablets e smartphones, sem comprometer o layout original para computadores?

28. **Ajustes de layout para tablets**

Como utilizar Media Queries para adaptar o cabeçalho, as seções, os cards, as imagens e os espaçamentos da Landing Page para telas de tablets?

29. **Ajustes de layout para smartphones**

Como reorganizar os elementos da Landing Page em telas menores, ajustando tamanhos de fontes, colunas, imagens, cards e formulários para melhorar a navegação em smartphones?

30. **Ajustes de espaçamento e alinhamento do cabeçalho**

Como corrigir o espaçamento e o alinhamento dos elementos do cabeçalho em tablets e smartphones, garantindo que o título, os links de navegação e o botão de inscrição fiquem bem distribuídos?
